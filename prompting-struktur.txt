CARA PAKAI (BACA SEKALI)
========================================================================
1. Kirim prompt SATU PER SATU, berurutan, ke AI coding agent (Claude Code, Cursor, atau sejenisnya).
   Jangan kirim prompt berikutnya sebelum Anda membaca laporan prompt sebelumnya.
2. Salin hanya teks di antara ">>> SALIN DARI SINI <<<" dan ">>> AKHIR PROMPT <<<".
3. Teks "LANGKAH PEMILIK" adalah pekerjaan Anda di luar agent (membuat project Supabase, hosting, mengisi
   data nyata). Lakukan sebelum mengirim prompt yang ditunjuk.
4. "CEK MANUAL UNTUK PEMILIK" adalah cara Anda memeriksa hasil dengan mata sendiri setelah agent melapor.
5. Bila hasil prompt sudah Anda setujui, awali prompt berikutnya dengan /1allclear. Agent lalu menandai
   prompt sebelumnya DISETUJUI di Ledger (PROJECT_PLAN.md Lampiran E). Tanpa itu, agent berhenti dan bertanya.
6. "GERBANG FASE" adalah pemeriksaan akhir fase. Jangan lanjut ke fase berikutnya bila gerbang belum lolos.
7. Bila agent gagal, gunakan PROMPT KHUSUS A (perbaikan). Bila kuota habis, PROMPT KHUSUS B (lanjutkan).
   Bila build rusak, PROMPT KHUSUS C. Bila ragu posisi pekerjaan, PROMPT KHUSUS D (status).
8. JANGAN pernah menempelkan kunci rahasia (service role, kata sandi database) ke chat. Simpan di
   .env.local di mesin Anda.
9. PROJECT_PLAN.md berisi ISI (aturan, skema SQL yang sudah diuji, daftar task). Berkas ini berisi PERINTAH.
   Bila keduanya berbeda, PROJECT_PLAN.md menang.
10. Sistem ini akan dipakai sungguhan. Jangan mengisi data usaha dengan angka karangan. Bila agent meminta
    angka (kebutuhan kain per potong, rekening, batas stok), jawablah dari data nyata atau biarkan
    TODO(pemilik).
11. Filter antislop v3.2.32 sudah terpasang di .agents/skills/ dan dirujuk dari AGENTS.md (clone sumber di
    anti-slop/). Gunakan mode during saat mengerjakan prompt UI, copy, aksesibilitas, mobile, dan kode agar
    slop dicegah sejak awal, atau gunakan PROMPT KHUSUS G (mode after) untuk audit hasil yang sudah jadi.
    Arah desain tetap dari PROJECT_PLAN.md §7; bila ada benturan aturan, §0.2 dan §7 menang. Jangan menimpa
    blok <!-- antislop:start --> sampai <!-- antislop:end --> di AGENTS.md.
